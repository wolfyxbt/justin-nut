# 植物大战僵尸（孙宇晨坚果版）

**Plants vs. Zombies (Justin Nut Edition)**

[在线游玩](https://wolfyxbt.github.io/justin-nut/)

一个无尽坚果保龄球同人游戏：从传送带取卡，把孙宇晨坚果或爆炸坚果放到红线左侧，让它们滚向僵尸；景甜向日葵定时结出普通坚果，曾颖向日葵则把喂给它的普通坚果转化为红色坚果。比谁撑得久、分数高。页面同时嵌入邵艾伦与孙宇晨的播客视频，可以一边玩一边看节目。

支持电脑和手机。点击「开始游戏」即可进入保龄球。游戏不会因为切换窗口或标签页而自动暂停，只有在菜单里点暂停才会停下；切走期间游戏照常推进，回来时会补上这段时间。游戏菜单中可以暂停、开关声音、调节游戏音量和重新开始。游戏音量只影响游戏自己的音效，不影响视频和设备音量。

## 怎么玩

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 取卡与放下 | 点击传送带卡片，再点击红线左侧的草坪 | 点选卡片后轻点草坪，或把卡片拖到草坪 |
| 拿起向日葵结出的坚果 | 点击坚果，再点击草坪放下 | 轻点坚果后轻点草坪，或直接拖到草坪 |
| 铲除向日葵 | 点击铲子，再点击植物 | 点选铲子后轻点植物，或拖动铲子到植物上 |
| 暂停、声音开关、游戏音量、重开 | 点击「菜单」 | 轻点「菜单」 |

键盘快捷键：`3` 取传送带最前面的卡片，`5` 选择铲子，空格暂停，`Esc` 取消卡片或铲子选择。向日葵产出的坚果拿起后，需要先放下，才能选择卡片、铲子或再拿一颗。

## 坚果保龄球

- 卡片由原版的传送带送来：开局 1 张，之后每 4 秒 1 张，带上超过 4、6、8 张时分别要等 4.25、5、10 秒，最多排 10 张。卡片从右端慢慢滑入，可以随时点取；放下一张后，要再点一次才能拿下一张。
- 坚果只能放在红线左侧的前三列，放下后会自动向右滚。两种向日葵也只能种在这三列的空格上。
- 传送带约 13% 的概率送来红色的爆炸坚果，撞到僵尸时炸掉相邻三行、前后约一格范围内的所有僵尸，每只 100 分，爆炸后消失。
- 传送带约 12% 的概率送来景甜向日葵。种下 10 秒后结出一颗孙宇晨坚果，之后每 30 秒一颗。点击产出的坚果会直接拿在手上，放到红线左侧的有效格子后开始滚动。传送带空了或满了都能拿取，拿取和放下不会增减传送带卡片。
- 传送带约 6% 的概率送来曾颖向日葵。喂一颗普通孙宇晨坚果，10 秒后产出一颗红色爆炸坚果，完成后可以再次喂食。已喂食的植物会在叶片旁长出红色小坚果，随转化进度逐渐长大并轻轻晃动，成熟后弹落到草地上；未喂食的植物没有果实。普通坚果可以来自传送带或景甜向日葵，支持点放和手机拖动。空手点击植物才显示简短提示，周围没有常驻文字和进度条。喂错植物或在转化中重复喂食时播放错误提示音，保留原物品。
- 僵尸会停下来啃两种向日葵。可以用铲子移除它们，腾出格子；铲子在传送带空时也能使用。
- 撞到僵尸后，普通坚果立刻斜着滚向相邻跑道，并一直斜着走：碰到草坪上下边缘折返，再撞到僵尸就反向。斜走途中不会命中路过的僵尸，只有正对跑道时才算撞上。第一次撞击时最上行必向下、最下行必向上，中间行随机，和原版 `Plant::UpdateBowling` 一致。
- 普通僵尸和旗帜僵尸一下就倒，路障僵尸第一下掉路障、第二下倒。
- 45 秒后有机会出现乒乓球僵尸：保留原版僵尸的脸部特征，搭配红色运动服与球拍，沿用原版跑动和啃咬的节奏。它的基础移动速度约为普通僵尸的三倍，需要三次普通坚果撞击；爆炸坚果和割草机可以直接击倒。
- 同一颗坚果连续命中奖励递增：第一下 100 分，第二下 200 分，第三下 300 分，以此类推。
- 僵尸无限出现，越来越密、越来越快，每隔一段时间来一大波。割草机用完后再被突破就结束，结算分数、消灭数和坚持时间，最佳成绩记在浏览器里。

## 边玩边看

电脑上标题牌和视频在左栏，标题在上、视频在下，草坪占据右侧大部分宽度；手机上标题和视频位于草坪上方。视频由 YouTube 的嵌入播放器直接播放，页面本身不承担视频流量。视频常驻显示，视频下方列出这期播客的全部章节，点一下就跳到对应时间开始播放，正在播放的章节会高亮。

游戏没有循环背景音乐，只保留种植、滚动、撞击与僵尸等音效，不会盖住播客声音；不想要音效可在「菜单」里关闭。重新开始游戏不会打断视频。浏览器不允许自动有声播放，首次需要手动点击视频的播放按钮。

更换视频：编辑 `index.html` 中 `id="watch-frame"` 的 `src`，把 `0Z-vhBvBmUY` 换成新视频的 ID，也就是 YouTube 链接里 `v=` 后面的那一段；`start=180` 是起始秒数，可以改动或删除；保留 `enablejsapi=1`，章节跳转依赖它。章节列表在 `assets/chapters.js` 中，按视频简介里的章节填写秒数和标题。视频需要上传者允许嵌入，否则播放器会提示前往 YouTube 观看。

## 本地运行

下载完整项目后，打开根目录的 `index.html` 即可游玩，保留旁边的 `assets` 文件夹。

也可以用 Node.js 24 或更新版本启动本地服务器，无需先安装依赖：

```sh
npm start
```

打开 `http://127.0.0.1:8080`。如需让同一局域网的手机访问：

```sh
npm start -- --host 0.0.0.0
```

在手机浏览器打开 `http://电脑的局域网IP:8080`。更换端口可使用 `--port 8081`。

## 开发与修改

游戏使用 HTML、CSS 和 Canvas，所有游戏资源随项目提供，本地运行时无需联网；只有嵌入的 YouTube 视频需要网络。页面外框、按钮、传送带、红线、开场文字都来自原版素材，音效也尽量使用原版对应的声音。
